# 🚀 Projeto em destaque

## CicloVida

> Plataforma desenvolvida durante um Hackathon da Prefeitura do Recife para reduzir o desperdício de alimentos por meio da tecnologia.

🏆 Desenvolvido por uma equipe multidisciplinar durante um desafio de inovação.

### Destaques

- 🥫 Plataforma para doação de alimentos
- 📍 Mapa interativo utilizando Leaflet e OpenStreetMap
- 🤖 Assistente virtual integrado à OpenAI
- 📱 Integração com WhatsApp
- 🏗️ Arquitetura baseada em microserviços
- 🌱 Foco em impacto social e sustentabilidade
